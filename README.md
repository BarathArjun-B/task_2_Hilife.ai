# Responsive Calculator Web App

This project is a responsive Calculator Web Application developed using:

- HTML5
- CSS3
- Vanilla JavaScript

The calculator performs basic arithmetic operations and supports both button clicks and keyboard input.

---

# Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Clear Function (C)
- Backspace/Delete Function
- Keyboard Support
- Responsive Design
- Continuous Calculations
- Expression Display
- Result Display

---

# Keyboard Support

The calculator supports keyboard operations:

| Key | Function |
|-----|----------|
| 0-9 | Numbers |
| + | Addition |
| - | Subtraction |
| * | Multiplication |
| / | Division |
| Enter | Calculate Result |
| Backspace | Delete Last Character |
| Escape | Clear Calculator |

---

# Continuous Calculation Feature

The calculator stores the previous result until the user presses Clear.
